Capítulo 27 · Parte 3: Prática · Seção 4.1

Prática: os exercícios

A Parte 3 do livro é feita de exercícios. Este capítulo explica como eles foram transformados em atividades e mostra, para cada capítulo de prática, quais capítulos de conceito ele retoma.

Começar Livro de referência

Neste capítulo

Apresentação 1. Por que resolver exercícios 2. Como as atividades estão organizadas 3. O mapa da Parte 3 Referências
Apresentação

Da teoria à bancada

A Parte 3 do livro reúne perguntas abertas, cada uma com um pequeno problema para resolver. Os autores avisam que ler o livro da primeira à última página não basta: só resolvendo os exercícios se chega a um conhecimento detalhado de redes (pág. 277 do PDF). O livro não traz as respostas. Nos capítulos de prática, cada atividade tem uma resolução comentada, conferida com código, mas tente resolver antes de abri-la.

Objetivos de aprendizagem

  • Saber como uma atividade dos capítulos de prática está organizada.
  • Encontrar, para cada capítulo de prática, os capítulos de conceito que ele retoma.

Antes de começar

A seção 4.1 do livro é só a abertura da Parte 3 (pág. 277 do PDF). Os exercícios começam no Capítulo 28.

Cada pergunta vale 10 pontos se acertada na primeira tentativa (5 depois). Ao concluir tudo de um tópico, você ganha a medalha dele.

Tópico 1

Ler não basta

1. O que o livro diz

A seção 4.1 abre a Parte 3 com um parágrafo curto (pág. 277 do PDF). Ela reúne uma série de perguntas abertas, pensadas para melhorar a compreensão dos temas do livro. Cada uma costuma trazer um pequeno problema para o estudante resolver, e foi pensada para levar a discussões com os monitores da disciplina.

Os autores fecham com um aviso: só se chega a uma boa compreensão dos temas resolvendo os exercícios propostos. Ler o livro da primeira à última página não basta para um conhecimento detalhado de redes de computadores.

Nota
O livro também indica questões de múltipla escolha e exercícios simples na plataforma INGInious (pág. 277 do PDF). Elas não estão no PDF, e a plataforma pede cadastro, por isso não são usadas aqui. As perguntas rápidas de cada capítulo fazem esse papel.

Tópico 2

Uma atividade em cinco etapas

1. As etapas

Nos capítulos de prática, cada grupo de exercícios do livro vira uma atividade, com cinco etapas:

  1. Relembre: o conceito em poucas frases, com o link para o capítulo onde ele foi explicado;
  2. O que o livro pede: os enunciados, traduzidos, com a página do PDF;
  3. Experimente: uma simulação que faz o papel do laboratório, com um desafio;
  4. Resolução comentada: fechada, para você tentar antes. Ela é marcada como "não está no livro", porque o livro não traz respostas, e cada número dela foi conferido com código;
  5. Fixação: perguntas rápidas.

2. Ferramentas que não rodam no navegador

Vários exercícios usam ferramentas que precisam de Linux e de permissões de administrador: programas em C com sockets, capturas com tcpdump, scripts do packetdrill, redes emuladas com o IPMininet. Neste site:

  • o código C e os comandos de terminal do livro aparecem como estão, com a página do PDF, sem execução;
  • o mesmo programa aparece em Python, num bloco que roda no navegador;
  • o Python do navegador não abre sockets de verdade, então a rede é simulada em memória, com o mesmo comportamento das chamadas do livro;
  • as saídas que o livro imprime, como capturas de pacotes e tabelas de rotas, viram os dados das simulações.
